Testing, explained

How I test an AI assistant

The model is not deterministic, so one kind of test is never enough.

1

Fast tests

about 6,000 cases · about 5 minutes · no cost
The model, database and embeddings are faked and blocked, so a test can never cost money or touch real data.
2

Tests that read the code

rules that must hold everywhere
No user content in logs. Writes need approval. One customer never reads another’s data. A real outage became a test.
3

Real-model evals

several runs each · scored by code
Does its character hold under pressure? Does it pick the right tool and resist hostile text? Compared to a saved baseline.
4

Production signals

counts, never user content
Cheap path or tool path, fallbacks, time, tokens, feedback and spend caps. Read the replies, not just the score.
Prose cannot guarantee behavior. Only mechanical checks can.
